# Collections and strings

| Tier | Rule | When not, pitfalls | Version | Source |
|---|---|---|---|---|
| A | Follow the CA18xx collection rules: `Any()` over `Count()` (CA1827), `Length`/`Count` properties over `Enumerable.Count` (CA1829), `IsEmpty` over `Count` (CA1836), `TryGetValue` over `ContainsKey` + indexer (CA1854), `TryAdd` (CA1864), `Array.Empty` (CA1825), no multiple enumeration of `IEnumerable` (CA1851), concrete types when possible (CA1859), no constant arrays as arguments (CA1861). | — | not stated | https://github.com/dotnet/docs/blob/main/docs/fundamentals/code-analysis/quality-rules/performance-warnings.md |
| A | Strings: `AsSpan` over `Substring` (CA1846), span-based `string.Concat` (CA1845), char literals for single characters (CA1847, CA1865-CA1867), `StringComparison` overloads instead of `ToLower`/`ToUpper` (CA1862), `StringBuilder.Append(char)` and typed overloads (CA1830, CA1834), `CompositeFormat` for repeated formats (CA1863). | — | not stated | https://github.com/dotnet/docs/blob/main/docs/fundamentals/code-analysis/quality-rules/performance-warnings.md |
| A | `FrozenDictionary` / `FrozenSet` (`ToFrozenDictionary`, `ToFrozenSet`) for lookups built once (startup) and read for the life of the app. | High creation cost; build only from trusted keys. | .NET 8 (API monikers) | https://learn.microsoft.com/en-us/dotnet/api/system.collections.frozen.frozendictionary-2 |
| A | Static lambdas (`static x => ...`) where a lambda needs no captured state, so no closure is allocated. | Cannot capture locals or instance state. C# 9 (not stated on the page; To confirm). | C# 9 (To confirm) | https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/operators/lambda-expressions |
| B | `SearchValues<T>` (`SearchValues.Create`) cached in a static field for repeated `IndexOfAny`/`ContainsAny` searches (CA1870). | Only pays off when the same set is searched often. | .NET 8 (API monikers) | https://learn.microsoft.com/en-us/dotnet/api/system.buffers.searchvalues-1 |
| B | `string.Create(length, state, action)` to build a string in place. | The destination span starts undefined: write every character. | .NET Core 2.1 (API monikers) | https://learn.microsoft.com/en-us/dotnet/api/system.string.create |
| B | Custom interpolated string handlers (`[InterpolatedStringHandler]`) to skip formatting when the result is not used. | A constant string bypasses the handler; `ref struct` handlers cannot hold an `await` hole; side effects in holes may not run. C# 10 (not stated on the page; To confirm). | C# 10 (To confirm) | https://learn.microsoft.com/en-us/dotnet/csharp/advanced-topics/performance/interpolated-string-handler |
| B | `CollectionsMarshal.AsSpan(list)` and `GetValueRefOrAddDefault` to update in place without copies or double lookups. | Unsafe class: never add or remove list items while the span is in use. | .NET 5 (API monikers) | https://learn.microsoft.com/en-us/dotnet/api/system.runtime.interopservices.collectionsmarshal |
| B | UTF-8 end to end: `u8` literals (`ReadOnlySpan<byte>`), `Utf8Parser.TryParse` on UTF-8 bytes. | `u8` literals are not compile-time constants and cannot be interpolated. C# 11 for `u8` (not stated on the page; To confirm). | C# 11 (To confirm) | https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/reference-types |
| B | `System.IO.Pipelines` (`PipeReader`, `PipeWriter`) for streaming parsers. | Always `AdvanceTo` after `ReadAsync`; never use the buffer after `AdvanceTo`; examined must not jump to the end when parsing one message at a time. | not stated | https://learn.microsoft.com/en-us/dotnet/standard/io/pipelines |
| B | `ReadOnlySpan<T>` properties instead of `static readonly` array fields for constant data (CA1878). | — | not stated | https://github.com/dotnet/docs/blob/main/docs/fundamentals/code-analysis/quality-rules/performance-warnings.md |
